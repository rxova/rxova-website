This is a test post.

It exists because I had just wired up a markdown pipeline across two repositories —
a schema package, a validator, a content collection, a renderer — and I wanted to
know whether it produced a page or my usual result, a bug. Tests are nice.
Production is nicer.

It produced a page. You are on it.

The plan was to delete this afterwards, the way you delete a `console.log()`. Then I
read it back and decided not to.

A blog whose first entry is a launch announcement started with marketing. A blog
whose first entry is someone checking whether the build works started with the build
working — which is closer to how anything here actually gets made.

So it stays. First post, permanently, load-bearing in no way whatsoever.
