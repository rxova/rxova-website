The hardening pass before 1.0, aimed at the failure modes real tabs hit. A tab restored
from the back/forward cache rejoins presence and the leader election instead of holding a
phantom seat; a value that cannot survive structured clone throws before touching local
state, where it used to silently diverge that tab from every peer; client ids come from
Web Crypto now, so the tie-breaker can no longer collide.

The hooks are also safe on a server at last — rendering in Next.js used to open transports
and run elections on timers nothing cleared. SSR now gets inert doubles, `useClientId`
hydrates cleanly, and the API's silent conflicts warn out loud in dev.

No React API changed, but anything asserting on client id shape sees the new 64-bit hex
format.
