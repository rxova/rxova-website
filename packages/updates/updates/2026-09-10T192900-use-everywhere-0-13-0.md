The 1.0 names from RFC 0001 arrive here, alongside the old ones: `useOnMessage`, `useWindowResult`,
`createStoreHooks`, `useSharedSelector` and `StoreHooks.store()`. The 0.x spellings keep working and
warn once per name in development (`UE2005`).

Two tools make the move mechanical:

- `use-everywhere-codemod` 0.1.0, its first release: `npx use-everywhere-codemod rename-1.0 src/`
  rewrites a 0.x codebase, and `--dry-run` lists the changes first.
- `eslint-plugin-use-everywhere` 0.2.0 checks `createStoreHooks` as well as `defineStore`, so a
  codebase part-way through the rename is linted either way.

Nothing breaks on 0.13. It is the release to take before 1.0.
