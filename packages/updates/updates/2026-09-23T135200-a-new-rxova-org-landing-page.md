The rxova.org landing page now opens straight on the projects. The old hero and its stacked list
are replaced by a rail beside a stage: pick a project from the rail, and the stage shows what it
does, how to install it and where its docs live.

Every project is tagged zero-dependency, and the page says what that means: each package declares no
third-party dependency, which `npm view <pkg> dependencies` confirms. The page only links to docs
that are live.
