`SUITE_SCOPE_NARROWED` no longer blocks a pull request that adds a package. A new
`vitest.config.ts` read as an exclude list that grew, so every new package was reported as a
narrowed suite, at `high`.

A config file that already existed still fires, including when it gains an `exclude` key it
never had.
