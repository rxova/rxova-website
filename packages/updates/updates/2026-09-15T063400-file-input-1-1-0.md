The file input is easier to use from a keyboard and a screen reader:

- One tab stop: Tab goes straight to the drop zone, not first to a hidden input.
- The drop zone is named after its field, so three file fields no longer all read "Choose a file or
  drop it here".
- Picking the same file again after it was refused or removed now runs the rules again.
- `onReject` always carries a `reason`. `attempt()` returns `FileAccepted | FileRejected`,
  which narrows on `accepted`.

`@rxova/react-inputs` 1.1.0 re-exports the two new types. Separately, OTP input 1.0.3 applies
`--rx-otp-font` to the visible slots and separators, not only to the hidden input.
