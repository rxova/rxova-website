## Code

Code blocks are where `--rx-font-mono` and the surface tokens meet, and where the
IBM Plex Mono weights actually get exercised.

```ts title="astro.config.mjs"
import { sharedStarlightConfig } from '@rxova/brand'

export default defineConfig({
  integrations: [
    starlight(
      sharedStarlightConfig({
        project: 'journey',
        sidebar: [{ label: 'Guides', autogenerate: { directory: 'guides' } }],
      }),
    ),
  ],
})
```

pnpm add @rxova/brand
