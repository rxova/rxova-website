For tabular facts a page reads from somewhere else (a manifest, a config) rather than writes
by hand: the frame, header row and caption `SizeTable` uses, with the columns and rows passed
in. The first column is a row heading; a cell given as `{ code }` renders in `<code>`. The box
scrolls sideways when narrow and is focusable, so a keyboard can reach it.

## Props

| Prop      | Type                 | What it does                               |
| --------- | -------------------- | ------------------------------------------ |
| `label`   | `string`             | The scrollable region's accessible name    |
| `columns` | `readonly string[]`  | The header row                             |
| `rows`    | `readonly DataRow[]` | One per row                                |
| `caption` | `string`             | Where the facts come from, under the table |

`DataRow` is `{ label: string, cells: readonly Cell[] }` and `Cell` is `string | { code: string }`.
`label` renders as the row's `<th scope="row">`.
