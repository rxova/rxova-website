import Story from '../../../components/Story.astro'
import SizeTable from '@rxova/astro-ui/components/SizeTable.astro'

A real table rather than cards: these are numbers people compare against whatever they ship
today, and a column of right-aligned tabular figures is the shape that supports comparing.
The box scrolls sideways on a narrow viewport and is focusable, so a keyboard can reach it.

## Props

| Prop          | Type                 | What it does                                  |
| ------------- | -------------------- | --------------------------------------------- |
| `rows`        | `readonly SizeRow[]` | One per package                               |
| `compression` | `string`             | The figure column's heading: `brotli`, `gzip` |
| `caption`     | `string`             | Where the numbers come from                   |

`SizeRow` is `{ pkg: string, entry: string, limitKb: number }`; the figure renders as
`≤ <limitKb> kB`.
