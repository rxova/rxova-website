Two panes: the install command in a terminal-looking box with a copy button, and a "Use" pane
holding whatever the page slots in. Write the snippet as a fenced block, so it gets the same
Shiki highlighting as the rest of the docs.

<Story title="Command beside a snippet" note="The command region is focusable and labelled: on a narrow screen it scrolls.">
  <QuickStart command="npm i @rxova/journey-core">

```ts
import { createLinearJourney } from "@rxova/journey-core";

const machine = createLinearJourney({
  context: { name: "" },
  steps: ["account", "review"],
});

await machine.navigate.goToNextStep();
```

  </QuickStart>
</Story>

## Props

| Prop      | Type     | What it does                                       |
| --------- | -------- | -------------------------------------------------- |
| `command` | `string` | The install line, also what the copy button copies |

The default slot is the "Use" pane. The copy button is the only client script; when the
clipboard is unavailable it stays silent rather than claiming a copy that did not happen.
