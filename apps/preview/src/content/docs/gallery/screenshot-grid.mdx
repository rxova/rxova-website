Something shown rather than described. Images go through Astro's `<Image>`, so they get a
width, a height and a srcset; each sits in a hairline frame with a numbered mono label and a
line of detail under it. The social card stands in for a screenshot here.

## Props

| Prop    | Type                                 | What it does            |
| ------- | ------------------------------------ | ----------------------- |
| `shots` | `readonly Shot[]`                    | The images, in order    |
| `link`  | `{ href, text, external?: boolean }` | A link beneath the grid |

`Shot` is `{ src: ImageMetadata, alt, title, body }`: `src` is an imported image, the way
Astro's `<Image>` wants it. The consuming site needs `sharp` for the optimisation.
