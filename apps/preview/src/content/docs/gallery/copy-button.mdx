An icon button: puts `text` on the clipboard and swaps its glyph for a tick for a moment,
announced to screen readers through a status line. `label` is its accessible name and tooltip. It draws in `currentColor`, so the same button works on a card, on the
page and on a terminal that stays dark in both themes. The caller places it, usually at the
end of a command line.

## Props

| Prop    | Type     | What it does                                       |
| ------- | -------- | -------------------------------------------------- |
| `text`  | `string` | What goes on the clipboard                         |
| `label` | `string` | The accessible name and tooltip, `Copy` by default |

Used by `QuickStart`, and on rxova.org by every command line: the project panels and /about.
