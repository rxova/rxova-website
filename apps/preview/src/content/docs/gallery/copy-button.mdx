import Story from '../../../components/Story.astro'
import CopyButton from '@rxova/astro-ui/components/CopyButton.astro'

Puts `text` on the clipboard and reads "Copied" for a moment, announced to screen readers
through a status line. It draws in `currentColor`, so the same button works on a card, on the
page and on a terminal that stays dark in both themes. The caller places it, usually at the
end of a command line.

<Story title="On the page" note="Inherits the text colour around it.">

</Story>

  </div>
</Story>

## Props

| Prop    | Type     | What it does                                                        |
| ------- | -------- | ------------------------------------------------------------------- |
| `text`  | `string` | What goes on the clipboard                                          |
| `label` | `string` | The accessible name, when "Copy" alone would not say what is copied |

Used by `QuickStart`, and on rxova.org by every command line: the project panels and /about.
