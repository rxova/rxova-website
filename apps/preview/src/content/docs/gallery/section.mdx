The shell every landing section sits in. `not-content` on the root opts the whole subtree out
of Starlight's prose styling, so a card grid or a stat band inside it keeps its own type scale.

## Props

| Prop      | Type      | Default | What it does                                     |
| --------- | --------- | ------- | ------------------------------------------------ |
| `title`   | `string`  |         | The `<h2>`                                       |
| `eyebrow` | `string`  |         | Small uppercase label above the title            |
| `lede`    | `string`  |         | One paragraph under the title, on a 62ch measure |
| `id`      | `string`  |         | For in-page links                                |
| `accent`  | `boolean` | `false` | Draws the gradient hairline above the heading    |

The default slot is the section body. A fenced code block or a paragraph placed directly in the
slot gets the landing's frame and muted style; nested components keep their own.
