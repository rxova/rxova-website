import Story from "../../../components/Story.astro";
import CtaBand from "@rxova/astro-ui/components/CtaBand.astro";

Title, lede and up to a handful of actions. One action is usually `primary`; the rest render
as outlined pills. External links get `rel="noopener"` and a small marker. Internal hrefs must
arrive base-aware, since the component writes them verbatim.

## Props

| Prop      | Type                   | What it does                                 |
| --------- | ---------------------- | -------------------------------------------- |
| `title`   | `string`               | The `<h2>`                                   |
| `lede`    | `string`               | One paragraph under the title, centred, 46ch |
| `actions` | `readonly CtaAction[]` | The buttons, in order                        |

`CtaAction` is `{ text, href, variant?: 'primary' | 'minimal', external?: boolean }`; `variant`
defaults to `minimal`. The primary fill reads `--rx-on-primary` from `@rxova/brand` for its
text, so it stays legible on the lightened dark-mode violet.
