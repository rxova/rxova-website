The one component that spends the full brand gradient: a lit frame, a blurred glow behind it,
and figures that count up the first time the panel scrolls into view. Values are rendered at
their final text, so with JS off or motion reduced it is a static panel. A value with no
leading digit (`MIT`) is left alone.

## Props

| Prop    | Type              | What it does        |
| ------- | ----------------- | ------------------- |
| `stats` | `readonly Stat[]` | The tiles, in order |

`Stat` is `{ value, label, note }`, all strings. `value` is a display string: the leading
number animates, whatever follows it (`kB`, `%`) is kept as the suffix.
