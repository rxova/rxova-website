The sales argument as a grid in the landing's language: a gradient hairline over each claim, the
icon in faint ink beside the title, the body under it. Three across at the wide measure, two on a
tablet, one on a phone. `icon` is a [Lucide](https://lucide.dev/icons/) icon name; the SVG is read from
`lucide-static` at build time and inlined, so nothing ships to the client and the site does
not import its own icon files.

## Props

| Prop    | Type                   | What it does         |
| ------- | ---------------------- | -------------------- |
| `items` | `readonly ValueItem[]` | The claims, in order |

`ValueItem` is `{ icon, title, body }`. `icon` is a `lucide-static` name such as `braces`;
an unknown name fails the build. `body` is set as HTML, so it may carry `<code>`.
