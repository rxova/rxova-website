`MemoryHub` and `MemoryTransport` moved to a `testing` subpath — they are a multi-tab
simulation harness, not runtime API, and on the package root they were a 1.0 promise and
a line in every production bundle's module graph.

```diff
-import { MemoryHub } from 'use-everywhere';
+import { MemoryHub } from 'use-everywhere/testing';
```

The React package also dropped `export * from '@use-everywhere/core'`, which had made its
public API implicitly whatever core happened to export. The list is written out now.
