Crafted input can no longer stall a run. Four parsers backtracked quadratically on text the patch
author controls, and each now reads in linear time:

- an `Overlock-Allow:` trailer;
- a `diff --git` header;
- an unterminated string literal;
- an `exclude` entry.

Every result is the same as before.
