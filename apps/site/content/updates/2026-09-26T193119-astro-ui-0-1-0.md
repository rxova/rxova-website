`@rxova/astro-ui` is a new package, and the first release is everything on rxova.org that renders:
the chrome (`SiteShell`, `Header`, `SiteFooter`, `ProjectSwitcher`, `ThemeToggle`, `ThemeScript`),
the Starlight preset and its overrides, the stylesheets, and the primitives (`PageHeader`,
`BackLink`, `ShowMore`, `VisuallyHidden`) that the landing, the blog and the updates stream used to
copy around. Until now these lived in `@rxova/brand`.

A docs site spreads `sharedStarlightConfig` from `@rxova/astro-ui/starlight`. A plain Astro site
imports `@rxova/astro-ui/styles/document.css` and the components from
`@rxova/astro-ui/components/*`. There is no barrel: each component has its own path, so a page only
loads the CSS of the components it imports. The package depends on `@rxova/brand` for the tokens,
so a site installs both.
