`@rxova/brand` is 1.0, developed in the open for the first time: the package moved from a private
repository into the public rxova-website one. It is also smaller than 0.15: design tokens,
typefaces and project data, nothing else. The components, `astro.css`, `chrome.css`, `starlight.css` and `sharedStarlightConfig`
have moved to `@rxova/astro-ui`, which shipped alongside it.

That move is the breaking change. A site that imported a component or a stylesheet from
`@rxova/brand` takes it from `@rxova/astro-ui` now; `tokens.css`, `fonts.css`, the assets and the
project data stay where they were. `chrome.css` no longer defines the short aliases (`--bg`,
`--fg`, `--max`, …), so styles read the `--rx-*` tokens directly. `projectFromBase` is now
exported from the entry point.
