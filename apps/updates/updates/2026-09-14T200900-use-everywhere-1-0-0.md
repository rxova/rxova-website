use-everywhere is 1.0, and so are `@use-everywhere/core`, `@use-everywhere/test-utils` and
`eslint-plugin-use-everywhere`. The stability policy applies from this release.

The only breaking change is the one 0.13 announced: the 0.x names deprecated there are removed.
Behaviour does not change, and the wire protocol stays at version 1, so tabs on 0.13 and 1.0 still
talk to each other.

Coming from 0.x, run `npx use-everywhere-codemod rename-1.0 src/`, review the diff, and take the
major.
